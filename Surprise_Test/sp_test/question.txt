As the application grew, this resulted in prop drilling, because some intermediate components were receiving customer data only to pass it on to the next component. Your task is to first demonstrate this problem, and then improve the application using the Context API and a custom hook. You will also use useEffect to perform an action whenever the customer's cart changes.
